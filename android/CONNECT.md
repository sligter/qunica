# Android 与手机连接

Android 8 及以上手机使用 ARM64 APK，x86_64 APK 用于对应模拟器。手机复用工作台的聊天、审批、独立任务并行、文件、终端和定时任务界面；后端和 Agent 运行在连接的电脑或服务器上。

## 选择连接方式

| 方式 | 操作 | 适用功能 |
| --- | --- | --- |
| 服务器直连 | 在应用输入受信任的 HTTPS 服务器地址，或扫描桌面远程模式“设置 → 手机连接”的服务器二维码，再登录同一账号。 | 聊天、审批、并行任务、文件、交付物、终端、定时任务，以及已配置电脑的桌面观察与接管。 |
| 桌面配对 | 在桌面本地模式“设置 → 手机连接”开启局域网连接或 VPS TCP 中继，在应用选择配对桌面并扫码。 | 复用桌面账号与数据；配对链路使用 Noise 加密。电脑桌面观察与接管需要服务器直连。 |

服务器二维码只含 HTTPS origin，不携带账号令牌；配对二维码有效期两分钟且只能使用一次。桌面远程模式展示当前服务器地址，不向内置本地服务提交远程账号令牌。局域网配对需要手机与电脑互通；VPS 中继需要自行配置 TCP 转发并保持电脑及转发进程运行。

切换到其他服务器会清除当前登录，已有桌面配对身份保留在 Android Keystore，可在连接页恢复。重新输入或扫描当前服务器地址保留登录。点击聊天左上角导航按钮，在侧栏查看当前连接方式、地址或切换连接。

## 手机工作区与交付物

聊天中的工作区入口提供文件、Git、电脑、定时任务四个带文字的标签；手机触控标签与容器使用匹配的高度。群任务支持独立线程并行；共享工作目录和电脑仍遵守服务端资源限制。

手机聊天顶部使用 48px 标题栏：导航、会话名称、助手与更多操作按正常布局排列。群聊的任务切换与任务操作占第二条 45px 工具栏，私聊不显示任务栏。连接详情收在导航侧栏，主聊天页没有额外品牌栏和连接栏。助手与导航沿用系统返回关闭面板，关闭后焦点回到相应入口；加载中与错误页面保留公共导航入口。

电脑交付物上限为 1000 MiB。Android 将响应流按最多 64 KiB 的块写入应用私有缓存，再打开系统文件选择器保存；无需将整个文件装入 JavaScript Blob。传输显示进度，账号变化、关闭面板或主动取消会中断未完成传输；长度不符和传输失败会清除缓存，且不自动重试。系统选择器取消保存属于正常退出。大文件保存需要足够缓存空间，页面关闭或应用进程结束不支持后台续传。

## 构建与验证

Windows 已安装工具链后执行 `pnpm android:build`；模拟器构建执行 `pwsh -NoProfile -File scripts/android.ps1 build -Target x86_64`。项目使用已有原生工程，不要重新运行 `tauri android init`。签名与 CI 约定见 [CI.md](CI.md)。本地调试 APK 不等同于正式签名发布，升级必须匹配原安装的签名证书。

真实手机的相机权限、扫码、软键盘、安全存储、保存选择器及切换网络需要真机验收；前端自动测试与 APK 构建不代替这些检查。
