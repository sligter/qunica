# 手机界面更新（2026-09-06）

安装包：[ARM64 APK](artifacts/qunica-0.1.1-mobile-ui-arm64-debug.apk)。沿用 `app.qunica.mobile` 和调试签名，可覆盖安装；不要先卸载，以免清除配对与登录记录。此次 UI 更新不要求更换桌面后端。

## 调整范围

- 聊天：群组与任务分行显示，次要操作收进带文字的菜单；消息正文不再为头像保留整列空白，消息操作在触屏上直接可见。
- 输入框：成员合并为一个选择入口，保留全部成员的 @ 功能；发送按钮独立占位，推理强度单独一行。手机回车换行、点击按钮发送，输入法确认候选字不会误发。
- 资源库：六个带文字的分类入口；新建和详情页隐藏分类栏，保留返回分类入口。搜索、新建、统计卡片和长标题适配窄屏。
- 设置：全屏面板，导航与表单重新排列；主题和语言选项可换行，开关保留紧凑外形并扩展触控区域。
- 技能导入：手机显示文件选择入口，选择按钮至少 44px 高，长文件名可换行。
- 其他：群组管理、日志行、Token 统计及筛选、弹窗、安全区和表单输入尺寸共用移动规则。桌面保留侧栏及横向布局。

## 验证

- 前端全量测试：117 个文件、813 项通过。最后的成员文案、技能导入和流式消息调整后，4 个相关文件的 58 项测试通过。
- TypeScript 和生产构建通过。ESLint：0 错误、14 条警告；生产构建仍有大于 500 KB 的 chunk 提示。
- 使用模拟 API 数据做 Chrome 布局检查：360px 中文深色、393px 中文深色、1280px 英文浅色。覆盖聊天、资源列表、Agent 新建与详情、服务商/MCP/技能/工作区新建、系统/媒体/日志/助手记录和 Token 统计。页面无横向溢出；长代码在代码容器内部横向滚动。
- 浏览器交互检查：输入区按钮无重叠；全部成员可选；任务菜单打开弹窗后正常关闭；430px 短视口内弹窗可滚动；群组管理可打开；统计筛选展开后操作不会意外收起。
- ARM64 APK 构建、ZIP CRC、APK v2 签名和 16 KB ZIP 对齐检查通过。校验和见 [SHA256SUMS-mobile-ui.txt](artifacts/SHA256SUMS-mobile-ui.txt)。

浏览器使用测试数据，这些结果不代表实体手机的软键盘、系统字体缩放、相机或实际加密连接验证。本次未在实体手机上安装。请覆盖安装后重点确认：输入法弹出与收起、长会话滚动、资源编辑保存、返回聊天、成员选择及横屏。
