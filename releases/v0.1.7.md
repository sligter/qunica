# Qunica v0.1.7

## Highlights

- Added ChatGPT device-code sign-in and existing-login checks for Codex ACP in Agent create/edit settings. Copy the authorization link and one-time code, cancel a pending login, and refresh runtime capabilities after authorization.
- Improved mobile provider model configuration: the model picker gets a full row, long names and IDs wrap in the menu, and the complete selected ID remains visible below the input. Default, test and delete controls no longer squeeze the model name.
- Added DeepSeek as a web search and page-fetch provider, with separate saved credentials and settings alongside Tavily. DeepSeek Fetch returns bounded Markdown and works for agents that enable Fetch without WebSearch.
- Corrected the AppImage archive-permission gate to inspect the real SquashFS modes rather than private directories created by runtime extraction.

## Downloads and upgrade notes

- Update both the backend and clients to use the new Codex sign-in entry. Install the Codex CLI (`@openai/codex`) on the backend host in addition to the ACP adapter; enable device-code login in your ChatGPT account or workspace settings when required.
- Codex keeps the credentials on the connected backend host. Agents that reuse that host's Codex login share the account. Qunica displays the authorization code and status, not account tokens.
- Configure DeepSeek in **Settings → Web search**. Search credentials are separate from chat model provider credentials, and switching providers preserves their settings.
- Back up server data before upgrading: migration `0047_deepseek_web_search` adds the new search settings.
- Android 8.0 or later: use `qunica_0.1.7_android-arm64-release.apk` for most phones, or `qunica_0.1.7_android-x86_64-release.apk` for compatible devices and emulators. Formal release APKs retain the existing release signing identity.
- Windows: choose the installer or `portable.exe`; macOS: choose the DMG for your chip; Linux: choose the matching package. Headless servers use the matching `qunica-server-*` archive and its SHA-256 checksum.

## 中文更新说明

- Codex ACP 新增 ChatGPT 设备码登录与已有登录状态检查。入口位于 Agent 新建/编辑表单的 **ACP → Codex**，支持复制授权链接和一次性验证码、取消等待，并在授权完成后刷新运行时能力。
- 优化手机端服务商模型列表：模型选择框独占整行，下拉名称和 ID 完整换行，选中后展示完整 ID；默认、测试和删除操作不再挤压模型名称。
- 网络搜索与网页抓取新增 DeepSeek 提供商，凭据及配置与 Tavily 分别保存；DeepSeek Fetch 返回受长度限制的 Markdown，单独启用 Fetch 的 Agent 也可使用。
- 修正 AppImage 发布权限检查，读取真实 SquashFS 归档权限，避免运行时解包器创建私有目录而导致误报。

请同时更新后端和客户端。Codex 登录需要后端机器安装 Codex CLI，并按需在 ChatGPT 账号或工作区设置中启用设备码授权；凭据由 Codex 保存，复用同一主机登录态的 Agent 共用账号。DeepSeek 在「设置 → 网络搜索」配置，搜索凭据与聊天模型凭据独立。升级前请备份服务器数据，本版包含新增搜索设置的数据库迁移。正式 APK 延续原发布签名；本地调试 APK 使用不同证书，不能保证覆盖安装。
