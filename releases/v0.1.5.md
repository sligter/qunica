# Qunica v0.1.5

- Fixed Linux AppImage startup for users other than the build owner. The upstream launcher is now packaged with mode `0755` instead of `0770`.
- Extended release checks to require readable files, traversable directories, and executable launchers inside the AppImage.
- Includes the v0.1.4 AppImage icon fix and all other v0.1.4 changes.

## 中文更新说明

- 修复 Linux AppImage 在其他用户下因启动器权限不足而无法启动的问题；上游启动器使用 `0755` 权限打包。
- 发布检查覆盖包内文件可读、目录可遍历，以及启动器对其他用户可执行。
- 包含 v0.1.4 的 AppImage 图标修复及其他更新。
