# Qunica v0.1.4

- Fixed the Linux AppImage's `.DirIcon` link by upgrading Tauri CLI to 2.11.4. Release builds now verify that the packaged icon and desktop metadata resolve inside the AppImage.
- Added configurable group decision-making models and settings, including automatic speaker selection that can defer when appropriate.
- Added a built-in group notes MCP server for external ACP agents.
- Fixed queued message cleanup when a turn stops or is rejected.
- Made login tokens non-expiring.
- Fixed conversation history refreshes overwriting locally appended messages.
- Fixed Android CI setup requesting the removed legacy SDK tools package.

## Downloads

- Android 8.0 or later: choose the `android-arm64-release.apk` package for most phones, or `android-x86_64-release.apk` for x86_64 devices and emulators.
- Windows: choose an installer or `portable.exe`; macOS: choose the DMG for your chip; Linux: choose the package for your architecture.
- Headless servers: choose a `qunica-server-*` archive.
