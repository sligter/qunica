# Qunica v0.1.6

## Highlights

- Added shared realtime synchronization across Web, desktop and Android, revocable device sessions, and recovery that does not replay execution commands.
- Added persistent controlled computers, browser and desktop observation/control, runtime bindings, setup guidance and computer deliverables up to 1000 MiB. Updated computer images render Chinese and emoji and provide more browser resources.
- Added durable scheduled tasks, event triggers and GitHub webhook integration, with computer and trigger panels available directly in conversations.
- Independent task threads can run in parallel while preserving per-thread execution ownership and computer resource exclusivity.
- Improved agent execution guidance, model sampling/reasoning settings, ACP context and workspace isolation, cancellation and event retention.
- Added saved desktop instance switching and improved Local/server setup. Android can scan server QR codes or pair with a desktop; reconnecting to the same server preserves sign-in.
- Redesigned mobile chat headers into a compact conversation bar and task toolbar. Connection details live in navigation, the Assistant button stays inside the header, and workspace tabs have readable labels and touch targets.
- Android computer deliverables stream through bounded native staging with progress, cancellation and the system save picker, avoiding a whole-file JavaScript Blob. Desktop deliverables use the native save dialog.
- Includes the AppImage extraction-check correction and prior launcher-permission fixes.

## Downloads and upgrade notes

- Android 8.0 or later: use `qunica_0.1.6_android-arm64-release.apk` for most phones, or `qunica_0.1.6_android-x86_64-release.apk` for compatible devices and emulators. These are release-signed packages; local debug APKs use a different certificate and may require uninstalling before installation and pairing again.
- Windows: choose the installer or `portable.exe`; macOS: choose the DMG for your chip; Linux: choose the package for your architecture.
- Headless servers: choose the matching `qunica-server-*` archive and verify its SHA-256 checksum.
- Back up server data before upgrading: this release adds database migrations for realtime synchronization, computers, automation and thread-level job ownership.
- Existing controlled computers need an explicit rebuild in Settings to use the updated execution image. Persistent home and browser identity are retained.
- Desktop observation and control require a direct server connection; Noise desktop pairing retains chat, account and file functionality. See the [Android connection guide](https://github.com/sligter/qunica/blob/v0.1.6/android/CONNECT.md).

## 中文更新说明

- 新增 Web、桌面与 Android 共享实时同步、可撤销设备会话及断线恢复；重连不重发执行命令。
- 新增持久受控电脑、浏览器与桌面观察/接管、运行时绑定和配置引导，电脑交付物支持最高 1000 MiB；更新镜像补充中文与 Emoji 字体并提高浏览器资源配置。
- 新增持久定时任务、事件触发和 GitHub Webhook，会话内可直接打开电脑及定时任务面板。
- 独立任务线程支持并行执行，同时保留同线程执行约束和电脑资源互斥。
- 改进 Agent 执行指引、模型采样与思考设置、ACP 上下文与工作区隔离、取消及事件保留处理。
- 桌面支持保存并切换实例，优化本地/服务器入口；Android 支持扫描服务器二维码或配对桌面，重连同一服务器保留登录。
- 重做手机聊天顶部：会话栏与任务栏分行，连接信息移入导航，助手按钮纳入标题栏；工作区四个标签补充文字并优化触控区域。
- Android 电脑交付物使用分块原生缓存、进度、取消和系统保存选择器，避免整文件 JavaScript Blob；桌面交付物使用原生保存对话框。
- 包含 AppImage 私有解包目录检查修正及既有启动器权限修复。

升级前请备份服务器数据，本版包含实时同步、受控电脑、自动任务和线程占用的数据库迁移。已有受控电脑需在设置中主动重建以采用新镜像，持久主目录和浏览器身份保留。正式 APK 与本地调试 APK 的签名不同，可能需要卸载调试版后重新安装、登录或配对。配对链路的桌面观察/接管仍需改用服务器直连。
