# Qunica v0.1.2

- 新增 OpenAI Responses API 供应商：流式文本、图片输入、工具调用与回传、推理摘要和 token 用量统计。
- 新增 Android 客户端及 PWA 支持，手机可扫码配对桌面，使用 Noise 端到端加密连接；支持自有 VPS TCP 中继、文件下载和移动端界面。
- 改进配对登录、会话恢复、设备撤销和手机连接安全。
- 新增 Web 终端、服务端目录选择、Docker 部署及首次认证配置。
- 完善缓存 token 和命中率统计、供应商与模型用量展示、消息复制及 Agent 工具调用进度。
- CI 自动构建 ARM64 和 x86_64 Android APK，并校验签名、对齐及 SHA-256；Android、桌面端和服务端均构建成功后发布。

## 下载

- Android 8.0 及以上：一般手机选择 `android-arm64-release.apk`，x86_64 设备或模拟器选择 `android-x86_64-release.apk`。
- Windows：安装包或 `portable.exe`；macOS：对应芯片的 DMG；Linux：对应架构的软件包。
- 无桌面服务器：选择 `qunica-server-*` 压缩包。

Android 正式版使用独立的发布证书，与此前本地 debug APK 的签名不同。旧 debug 用户需先卸载旧版再安装，并重新配对；请先保存需要保留的本地信息。后续正式版沿用同一证书，可覆盖升级。手机仍需连接运行中的桌面端或服务器，不在手机上运行 Agent CLI。
