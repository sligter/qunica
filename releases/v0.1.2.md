# Qunica v0.1.2

- Added an OpenAI Responses API provider with streaming text, image inputs, tool calls and results, reasoning summaries, and token usage tracking.
- Added Android client and PWA support, including QR code pairing with the desktop app, Noise end-to-end encrypted connections, optional self-hosted VPS TCP relay, file downloads, and a mobile interface.
- Improved pairing sign-in, session recovery, device revocation, and mobile connection security.
- Added Web Terminal, server directory selection, Docker deployment, and first-run authentication setup.
- Improved cached-token and hit-rate metrics, provider and model usage reporting, message copying, and Agent tool-call progress.
- Fixed unmoderated mesh groups where members stopped responding: an Agent's public @mention now requests that member's reply, including members who were previously silent, within the turn's step and hop budgets.

## Downloads

- Android 8.0 or later: choose `android-arm64-release.apk` for most phones, or `android-x86_64-release.apk` for x86_64 devices and emulators.
- Windows: choose an installer or `portable.exe`; macOS: choose the DMG for your chip; Linux: choose the package for your architecture.
- Headless servers: choose a `qunica-server-*` archive.
